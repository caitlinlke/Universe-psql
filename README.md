# Universe-psql


This is my completed project for the **freeCodeCamp Relational Database Certification**. 

## Project Description
A relational database built using **PostgreSQL** that models a miniature universe. It contains structured schemas and data relationships mapping out:
* Galaxies
* Stars
* Planets
* Moons
* Asteroids

The database structure includes primary keys, auto-incrementing fields, unique constraints, and foreign key relations to maintain data integrity across all celestial bodies.
